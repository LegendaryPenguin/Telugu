# Telugu — a personal app for learning to *speak* Telangana Telugu

A single-user web app for one goal: **speaking and understanding colloquial Telangana Telugu** well enough
to talk with my girlfriend. No reading, no writing — everything is shown in romanization + English, and
audio does the heavy lifting.

> Full design and rationale live in [`docs/PLAN.md`](docs/PLAN.md).

## The goal (and what it rules out)

- **In scope:** understanding spoken Telugu, and producing it out loud — pronunciation, listening, conversation.
- **Out of scope:** reading and writing Telugu script. You never see the script; it only lives *under the hood*
  to drive good text-to-speech.
- **Dialect:** Telangana (Hyderabad-style everyday speech).
- **Register:** realistic casual + light natural Tenglish (how couples actually talk). Sound-foundation
  drills stay clean.

## The four pillars

| What it does | Pillar |
|---|---|
| Hear proper pronunciations | **TTS** — neural/browser voice reads phrases; audio cached |
| Speak and get judged | **STT + pronunciation scoring** — mic → transcript → score |
| Have conversations | **Claude** — role-plays, talks back, corrects gently |
| Quiz + track progress | **SRS** — spaced repetition, streaks, weak-sound tracking |

## Key design decisions

- **Web PWA** (React + Vite + TS + Tailwind) — laptop + phone, installable, mic/audio native.
- **Pluggable speech layer** — runs on free browser TTS/STT today; swapping in Azure/Google is a config
  change, not a rewrite. (Hybrid quality strategy.)
- **Three-layer content** — every phrase stored as `Telugu script` (drives audio) → `romanization` (what you
  read) → `English` (meaning). Generated by Claude, tuned to Telangana.
- **Personalization is the point** — log real situations ("tell her I missed her") or paste something she
  said, and the app builds a drill around it.

## Run it

```bash
# 1) the web app
cd web
npm install
npm run dev            # http://localhost:5173

# 2) (optional) the server — needed for Talk + Add-phrase, and cloud voice
cd ../server
cp .env.example .env   # add an LLM key (Anthropic / OpenAI-compatible / 0G)
npm start              # http://localhost:8787  (Vite proxies /api to it)
```

The Today, Sounds, Phrasebook, Shadow, and Quiz screens work with **no server** and
**no AI**. Every built-in phrase ships with a pre-generated MP3 (`web/public/audio/`),
so you can hear pronunciations offline even if the device has no Telugu voice. The
browser voice is the fallback for custom phrases. Talk and Add-phrase are the only
parts that need the LLM configured.

Regenerate the bundled audio any time content changes (idempotent; skips existing):

```bash
cd web && npm run gen-audio             # uses edge-tts if installed, else Google
cd web && npm run gen-audio -- --force  # re-generate everything (e.g. after voice upgrade)
```

For **neural quality** audio (highly recommended), install [edge-tts](https://github.com/rany2/edge-tts)
once — it's free, keyless, and produces natural-sounding neural Telugu:

```bash
pip install edge-tts   # or: pipx install edge-tts
```

The script auto-detects it and falls back to Google Translate TTS otherwise. Cloud
TTS (Sarvam / Google) remains an optional live-voice upgrade path — see `server/.env.example`.

> Telugu browser voice is best on Chrome/Android and Safari (macOS/iOS); desktop
> Chrome/Windows often lacks it. Speech *input* (mic scoring) is Chrome-only today.

- [x] **Talk** — Claude role-plays (girlfriend/friend/shopkeeper), speaks + corrects
- [x] **Quiz** — listening comprehension (hear Telugu, pick meaning)
- [x] **Add** — generate a phrase, decode something she said, or break down a subtitle
- [x] **Watch** — cinema ladder + verified channels, graded listening, learner films, tools

### Known gaps / future work
- Pronunciation scoring is edit-distance similarity today. **No vendor sells Telugu
  phoneme-level scoring** — a real upgrade means a self-hosted forced-alignment + GOP
  scorer (AI4Bharat IndicConformer). See `docs/PLAN.md`.
- No provider offers a **Telangana-accent voice** — audio is standard `te-IN`; the
  Telangana flavor is in the *words*, which we control.
- Starter content is an authored draft pending **native review**.
